# Ready-made character portraits

Open [the prototype](index.html) in a browser. Person and Animals & fantasy each open their own illustrated set on the same screen. Switching categories preserves that category's selections while the preview is open.

- Person has ten head designs in a looping portrait picker, four skin tones, four clothing layers and three hats plus a no-hat option.
- The combined gallery has four species and four body colors.
  It also has a dragon, forest sprite and little wizard with four body colors.

The canvas art uses heavy outlines, saturated colors and round expressions inspired by the existing Dozy portraits. Heads, clothes and hats are drawn independently in the same coordinate space. Separate looping selectors show the chosen character, clothes and hat. The fixed portrait preview draws the selected layers together. Saving is a simulation.

See [the first proposal](../proposal-avatars/index.html) for the alternative that cycles individual features.
