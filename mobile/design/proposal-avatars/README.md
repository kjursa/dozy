# Character portraits in the form

Open [the prototype](index.html) and add a character, or edit Oliver or Pippin. Portrait selection stays in the character form. The preview updates immediately when you switch an option.

- **Person:** Face, Hair and Outfit. A clothing option includes a style and a color.
- **Animal:** Head selects the species. Ears can follow that species or use a rounded or floppy shape. Accessory adds an optional bandana, scarf or bow. The prototype assigns a coat color to each species.
- **Make-believe:** Cycle through ready-made portraits in one row.

The portrait updates independently from the personality and appearance used in the story. Changes to the character list last until the page is reloaded. Portrait art is illustrative.
